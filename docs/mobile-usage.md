# 手机端使用指南（安卓 / 鸿蒙）

两端 UI 与功能一致，引擎为同一套 Go 代码。

## 快速开始

1. PC 面板（`caotun web` → http://127.0.0.1:21877）点「手机扫码导入 → 显示二维码」
2. 手机 App 点「扫码接入」对准二维码——地址、密码自动导入，扫码完成立即拉起 VPN
3. 首次连接弹一次系统 VPN 授权框，点「允许」，状态栏出现钥匙图标即全局代理生效
4. 首页大圆钮 = 连接/断开开关；服务器列表支持多配置、编辑、删除、切换（切换后自动重连）

## 代理域名（白名单，核心设置）

- **只有列表里的域名走隧道**（由 VPS 解析，防污染），其余流量全部直连
- 默认 8 项：`github.com` `google.com` `googleapis.com` `gstatic.com` `youtube.com` `huggingface.co` `android.com` `dl.google.com`
- **一行一个域名**；子域名自动覆盖（填 `google.com` 即含 `translate.google.com`）
- 清空保存 = 恢复默认 8 项
- 改完**断开重连**生效
- 打不开某国外网站 = 它不在白名单里，加一行即可；白名单里的网站打不开时先断开重连再试

## 直连 DNS

- 只影响**白名单之外**域名的解析（这些域名未被墙，国内 DNS 即可）
- 默认 `223.5.5.5`，可逗号分隔多个按序尝试
- 改完断开重连生效

## 日志采集（反馈问题必备）

| 端 | 采集方式 |
|---|---|
| 安卓 | 开发者选项开启 USB 调试 → `adb shell run-as com.caotun.app cat cache/caotun/engine.log` |
| 鸿蒙 | `hdc shell hilog -x --domain 0xC0A0`（须带 `--domain`，默认输出不含引擎日志） |

日志内容：引擎启动（含白名单条数）、每条连接的建立/关闭与双向字节数、拨号失败原因、panic 堆栈、每 5 秒的 tun 收发包计数。

## 预期行为（不是故障）

- `ping` 任何域名都 100% 丢包：引擎只转发 TCP 和 DNS，ICMP 不走隧道；且 shell 的 ping 解析路径与 App 不同，不能代表 App
- QUIC/HTTP3 不通：UDP 除 DNS 外全部拒绝，浏览器会自动回落 TCP
- 国内网站与应用完全不走隧道：白名单模式的设计行为

## 已知边界

- VPN 服务随宿主进程存活；系统强杀后 App 会按「自动重连」逻辑拉起
- 鸿蒙上架应用市场需通过华为 VPN 权限审核；自用调试签名即可
- 系统开启「私人 DNS」（DoT）时会产生对哨兵地址 853 端口的连接尝试，引擎直接拒绝促其回落普通 DNS，属正常
